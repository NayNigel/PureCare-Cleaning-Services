DEPLOYMENT AND MAINTENANCE
1. Make website changes in the project files.
2. Commit and push the updated files to the main branch.
3. GitHub Pages automatically publishes changes from the configured main branch and root folder.
4. Allow the deployment to finish, then open the live website.
5. Refresh the affected pages and test the changed features.
6. If the project is moved to a different repository or its published URL changes, update every page's canonical/Open Graph references where applicable, all sitemap.xml page URLs, and the Sitemap: line in robots.txt.
7. Submit sitemap.xml through Google Search Console if the site is intended to be indexed.
